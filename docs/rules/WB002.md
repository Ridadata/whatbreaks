# WB002 — model removed

A model present in the base commit is gone from the change.

| Situation | Severity | Confidence |
| --- | --- | --- |
| Another node still `ref()`s it | `breaking` | `confirmed` |
| Nothing references it, whole project analysed | `safe` | `likely` |
| Nothing references it, coverage partial | `possibly_breaking` | `likely` |

## Why this one can be `confirmed`

Almost every whatbreaks finding is capped at `likely`, because it is built from
SQL the tool reconstructed rather than SQL dbt compiled.

WB002 breaking is the exception. `depends_on` comes from dbt's own resolution of
`ref()`, recorded in the manifest. A dangling reference is therefore a fact, not
an inference — dbt itself would refuse to compile.

## Example

```
BREAKING  WB002  model stg_payments was removed
          still referenced by: orders, payments_summary
          confidence: confirmed
```
